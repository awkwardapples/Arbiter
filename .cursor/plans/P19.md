### F2 replay (`app/audit/replay.py`)

```python
class HumanOverride(BaseModel):
    reviewer: str; role: str; decision: str; rationale: str; review_id: str; at: datetime | None

class ReplayResult(BaseModel):
    match: bool
    diff: list[str]
    checks: ReplayChecks
    human_override: HumanOverride | None = None        # new
    machine_outcome: str | None = None                 # new
    machine_source: Literal["stored", "reconstructed"] | None = None  # new: "says so" for old cases
```

When the stored record has `outcome_reasons == ["HUMAN_REVIEW"]`:

1. **Machine.** Take `store.machine_decision_for(case_id)`.
   - **Stored:** run today's checks on that record: policy hash, recompute through `decide` and `force_escalate`, content hash, record hash, facts diff.
   - **Missing** (case reviewed before P19): re-decide from the human record's `policy_inputs`. `machine_source="reconstructed"`. The check covers the policy hash and the facts diff, and the record hash is reported as not checkable (`record_hash` reflects the human record's content hash only).
2. **Review.**
   - The latest `reviews_for(case_id)` exists.
   - Its `decision` equals the stored outcome, and its `human_run_id` equals the stored `run_id`.
   - The human record's own content hash holds.
   - The human record equals the machine record except `outcome`, `outcome_reasons`, `run_id`, `created_at` and `record_sha256`.
   - The reviewer's role is in `policy.roles`, and its rank is at least the highest rank in `required_approvals(human_record, policy)`.
3. **Signatures.** As today, over all contracts for the case.
4. `match = machine_ok and review_ok and signatures_ok`. `diff` names what failed, for example `outcome` or `review.decision`.

Unreviewed cases follow today's path unchanged, with the new fields set to `None`.

`app/cli/audit.py::_replay`: when `human_override` is set, it prints the sentence, for example "Machine decision ESCALATE replays identically. Overridden by tprm_lead (lead.reviewer@example.com) to APPROVE_WITH_CONDITIONS: Bridge letter accepted…". The sentence goes to **stderr** and the JSON stays the only stdout line, so existing consumers that parse stdout keep working. The exit code is unchanged (1 if not `match`).
