## Interfaces

`app/cli/examples.py` calls `app.orchestrator.run` (the real system). It does not read `output_examples/`, `input_examples/expected.json`, or `data/evals/`.

```python
def register(sub: argparse._SubParsersAction) -> None: ...
def cmd_examples(args: argparse.Namespace) -> None: ...

def example_header(*, run_id: str, mode: dict[str, str], provider: str, git_sha: str, generated_at: str, p50_ms: float, n_runs: int) -> dict[str, object]: ...
def write_example(path: Path, *, header: dict[str, str], response: RunResponse) -> None: ...
def export_trace_schema(path: Path) -> None: ...
```

`cmd_examples` behaviour:

- Inputs: every `input_examples/example_*.json`, sorted by name. `expected.json` is not an input.
- Before each run: `ARBITER_MEMORY=off`, `get_settings.cache_clear()`, and a new temporary directory passed as `Deps(var_dir=...)`. One example cannot see another's store.
- Default (no `--live`): `SAMPLE_MODE=true`, `LLM_PROVIDER=offline`. Header `mode` is `"sample"`. This matches the current eval (`eval/results/20261022T080517661769Z/env.json` is offline, `model_ids` is `[]`) and does not need credentials.
- `--live`: do not force sample mode; `LLM_PROVIDER=auto`. Write the file only if that run's response mode is Zetaris plus Meterless. Header `mode` is `"live"`. If the run fell back, exit non-zero and do not label the file live.
- Header object, written with the response under `{"header", "response"}`: `generated_by` is exactly `python run.py examples`, plus `run_id`, `mode`, `git_sha` (`git rev-parse HEAD`), `generated_at` (UTC, CLI clock only).
- Copy `logs/trace-<run_id>.jsonl` to `logs/examples/trace-<run_id>.jsonl`. The source line is whatever `Tracer` wrote.
- Also write `docs/trace_schema.json` from `TraceEvent.model_json_schema()`.
