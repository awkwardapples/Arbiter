# P18-A plan: streaming and read API for the console (lane `18a`)

Tool: Claude Code (Opus 5.5). Spec: `docs/spec/release3/P18A_STREAM_API.md`.

## 1. Goal

Give the web console a backend it can drive entirely over HTTP, without changing any decision.
`POST /runs` starts the **unchanged** `app.orchestrator.run()` on a background thread and returns
the run id at once. `GET /runs/{id}/events` streams the run's trace events over SSE, replaying from
any index so a browser can reconnect. Read-only endpoints expose the query registry, the USL model,
the agent roster, the whitelisted Nightshift proof, the DQ parity results and the committed
recordings. Three new trace events make visible what the trace hides today: the moment a model
request is sent, each contradiction with its two sides, and each policy decision. When
`web/dist/index.html` exists, FastAPI serves the console at `/console/`. `POST /run` stays
synchronous and unchanged; no committed trace is edited.

## 3. Interfaces

### 3.1 `app/runhub.py`

```python
MAX_ACTIVE = 2
RETAIN = 50

class Busy(Exception): ...

class RunRecord(BaseModel):
    run_id: str
    started_at: datetime
    finished_at: datetime | None = None
    state: Literal["running", "done", "error"]
    events: list[dict]
    response: dict | None = None
    error: str | None = None

class HubTracer(Tracer):
    def __init__(self, run_id, *, mode, log_dir="logs", hub: RunHub) -> None
    def event(self, *a, **kw) -> TraceEvent      # super().event(), then hub._append(run_id, evt.model_dump(mode="json"))

class RunHub:
    def __init__(self, *, run_fn: Callable[..., RunResponse] | None = None, log_dir: str = "logs")
    def start(self, request: RunRequest) -> str                       # Busy if active >= MAX_ACTIVE
    def snapshot(self, run_id: str, start: int = 0) -> tuple[list[dict], RunRecord]   # KeyError → 404
    def wait(self, run_id: str, after: int, timeout: float) -> bool   # True when len(events) > after or state != running
    def list_recent(self, limit: int = 20) -> list[RunRecord]

def get_hub() -> RunHub        # process singleton; routes use it as a FastAPI dependency so tests can override
```

- `start()` counts running plus pending starts under the condition lock, spawns a daemon thread that
  calls `run_fn(case, options=RunOptions(...), deps=Deps(tracer_factory=factory))` (default
  `app.orchestrator.run`, looked up at call time so tests can monkeypatch it), and waits up to 10 s
  on a per-start `threading.Event` set by the factory. If the factory is never called, the thread's
  error is raised as an `ArbiterError` (or a timeout error) instead of returning a fake id.
- Thread completion sets `state=done` + `response`, or `state=error` + `error` (exception type and
  message, no stack), `finished_at`, then `notify_all()`. Retention trims to the last 50 records
  (never a running one); trace files are never touched.
- One `threading.Condition`; no asyncio inside the hub.

### 3.2 `app/api/routes_stream.py`

- `POST /runs` → 202 `{run_id, events_url, status_url}`; `Busy` → 429 `ErrorResponse`
  (`type="Busy"`, `recoverable=True`, message "Two assessments are already running. Wait for one to finish.").
- `GET /runs/{run_id}/events` → `StreamingResponse(media_type="text/event-stream")`. Start index:
  `Last-Event-ID + 1`, else `?from=N`, else 0. Async generator: yields buffered events as
  `id: <index>\nevent: trace\ndata: <json>\n\n`, then loops `await asyncio.to_thread(hub.wait, id, n, 1.0)`;
  emits `: keep-alive\n\n` after 10 s without output; ends with `event: done` (`run_id, status,
  case_id, outcome, execution_time_seconds, mode`) or `event: error` (`run_id, message`). 404 for an
  unknown id (checked before the stream starts).
- `GET /runs/{run_id}` → `{run_id, state, n_events, started_at, finished_at, response?, error?}`.
- `GET /runs` → `[{run_id, state, case_id, started_at}]`, `case_id` parsed from the `start_run` event.

### 3.3 `app/api/routes_evidence.py`

- `GET /registry/queries` → `[{id, description, systems, control_ids, params, sql}]`. `sql`: the
  query's `sql_usl` (live USL) or `sql`, with every `{T.<table>}` replaced via `registry.table_name()`
  for the current settings (`SAMPLE_MODE` → duckdb names; else zetaris + `ZETARIS_QUERY_LAYER`).
  Parameter tokens (`:vendor_id`) stay as written. Handler queries return `sql: null`.
- `GET /usl/model` → `{name, namespace, tables: [...], catalogue_tokens}` from `load_model()` and
  `catalogue_tokens(compact_catalogue(model))`.
- `GET /agents` → `AGENT_ROSTER` from `agent_roster.py`: nine `{name, trace_name, kind, lane, can, cannot}`
  rows. `name` is the human label used on the bench (Planner, Evidence, Evaluator, Policy engine,
  Memory (H-MEM), Challenger, Reporter, Scout guard, Action executor); the other five fields copy
  the README "How it works" table verbatim (lane `–` kept as `"–"`).
- `GET /evidence/nightshift` → built by whitelist, never by copying: per lane (`fast`, `deep`) only
  `sent_model, response_model, routed_model, requested_mode, routed_mode, mode_coerced, receipt_id,
  latency_ms, tokens_in, tokens_out`; top level `timestamp`, `base_url_host` (`host:port` from
  `urlsplit`), `deviations` (`kind, detail, model, receipt_ids` per item). Path is a module
  constant so the test can point it at a temp file.
- `GET /evidence/parity` → from `docs/passes/P1-B_parity.json` and `zetaris/dq_rules.yaml`:
  `query_layer, source_mode, all_green, table_counts, rules, invalid_by_table, query_comparisons
  {total, ok}, kev_checks {total, ok}`. The parity file repeats `contract` once per rule;
  `invalid_by_table` is de-duplicated by table (`zetaris` ← `zetaris`, `mirror` ← `duckdb`). No
  per-rule counts are invented.
- `GET /recordings[?include_failed=true]` and `GET /recordings/{run_id}`. Index built once per process
  (cached on first use; `reset_index()` for tests) from fixed globs:
  `logs/examples/live/trace-run-*.jsonl` → `live_example`; `eval/results_live/*/traces/trace-run-*.jsonl`
  → `live_eval`; `logs/examples/session/trace-run-*.jsonl` → `live_session`;
  `logs/examples/sample_mode/trace-run-*.jsonl` → `sample_example`;
  `logs/examples/live_failed/trace-run-*.jsonl` → `failed: true` (kind `live_example`, listed only with
  the flag). Meta per file: `case_id` (`start_run`), `outcome` (`complete_run` first word),
  `duration_s` (first to last timestamp), `recorded_at` (first timestamp), `mode` (first event),
  `model_ids` (sorted distinct `model` on `model_call`), `n_events`, `n_model_calls`, `n_fallbacks`
  (status `fallback`), `n_queries` (`query_run`), `path` (repo-relative), `vendor_name`.
  Detail: id must match `^run-[0-9a-f]{12}$` **and** be in the index, else 404; the file path comes
  from the index entry only.
- Vendor name: `CASE-<digits>` → `VND-<digits>` (inverse of `case_id_for`), then `legal_name` from
  `DuckDBBackend().run("Q_VENDOR_PROFILE", ...)`; a non-digit suffix (inline digest) → "Inline
  submission"; no row → `null`. Looked up once per case id while indexing.

### 3.4 `app/api/routes_web.py`

### 3.5 Trace events

- **`model_request`** in `_Call.chat()`, just before `self.provider.chat(...)`, only when
  `self.tracer` is set: `agent_name` as the `model_call`, `input_summary
  "purpose=<p> route=<r> attempt=<n> prompt_chars=<c>"`, `output_summary "sent to <provider.name>"`,
  `provider`, `route`, `purpose` set, `model` null. Fires for attempt 1 and the repair attempt 2,
  so every `model_call` (success, retrying or fallback) has a preceding `model_request`.
  `scripts/check_trace.py --require-live` is unaffected: it needs `model` set on a success, and
  `model_request` has none, so failed live attempts still fail it.
- **`EvaluatorAgent contradiction_found`** after `derive()`, once per `(key, claim_id)` per run. The
  agent instance keeps a `set` of reported keys, reset when `state.run_id` changes. Values: lists
  joined with `,`, then `mask_secrets`, then truncated to 80 characters (masking before truncation
  so a cut cannot expose half a secret). `system` and `record_key` from `sor_provenance`.
- **`PolicyEngine decide`** in `_act()` after the DECIDE_1 and DECIDE_2 `_decide()` calls:
  `input_summary "facts=<n> contradictions=<m> precedents=<k>"`, `output_summary "outcome=<O>
  tier=<T> failing=<ids with state FALSE> unknown=<ids with state UNKNOWN>"` (comma-joined, empty
  when none). Emitted before the existing `Orchestrator redecide` event; nothing else changes.

## 5. Risks and questions

1. **Branch name.** This worktree is on `p18a-stream`; the README names `p18a-stream-api`.
   Recommend: push as `p18a-stream` (the worktree branch) and open the PR from it. Say if you want
   `p18a-stream-api` instead and I will push `p18a-stream:p18a-stream-api`.
2. **Dev CORS setting.** `ARBITER_DEV_CORS` should come from `app/config.py`, but that file
   belongs to lane 19. Recommend: read `os.environ.get("ARBITER_DEV_CORS") == "1"` in `main.py`
   with a comment, and move it into `Settings` after 19 merges. Alternative: ask 19 to add the field.
3. **"Three include_router lines".** The static mount cannot go through `include_router`
   (mounts on an `APIRouter` are not carried over reliably), so `main.py` gets two
   `include_router` lines plus `routes_web.install(app)`. Same footprint, same revert story.
4. **Recordings index timing.** The spec says "indexed once at startup". I will build it on first
   request and cache it for the life of the process (no slower startup, same behaviour). Say if you
   want a startup hook instead.
5. **Root-level `logs/examples/trace-run-*.jsonl`** (12 P5-B era offline traces) fit none of the four
   kinds, so they are not indexed. P20 owns that folder.
6. **T5 costs 12 s** of wall time, as the spec states. I keep the 10 s keep-alive and the 12 s sleep
   rather than shrinking them with a test knob.
7. **Threads in tests.** Hub threads are daemons; tests wait for `done` or release the stubs so no
   run outlives its test's `tmp_path`.
