# P18-D plan: Sources, Provider, New vendor, Memory, Review, Audit, Evaluation

Lane `18d`, branch `p18d-pages`, PR into `p18-console`. Tool: Claude Code (Opus 5.5).

## 1. Goal

Replace the seven placeholder pages that P18-B part 1 left for this lane with real pages in the console's design (P18_00_DESIGN §3–§5), so that every Streamlit capability in design §9 owned by 18d exists in the web console. The two sponsor pages carry the most weight: **Sources** draws the Zetaris USL `vendor_risk` as a dagre-laid React Flow ERD with its foreign keys, the two undeclared joins, the registry queries that read each table, the five DQ rules and the parity result; **Provider** proves the Meterless Nightshift connection and the Nemotron models that served calls, with the token never rendered. The New vendor questionnaire builds exactly the `CaseInput` the Streamlit form builds and hands off to the run view. No decision logic, no API changes.
