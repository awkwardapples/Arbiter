# P18-C plan: the Case page and the Cases queue (lane `18c`)

Tool: Claude Code (Opus 5.5). Spec: `docs/spec/release3/P18C_CASE_AND_QUEUE.md`. Design: `P18_00_DESIGN.md` (binding).

## 1. Goal

Rebuild the Streamlit Cases and Case pages in the web console, in the P18 design, with parity for every
design §9 row from "Cases" to "Technical details". Cases is a one-sentence summary, URL-backed outcome
and tier chips with counts, and a keyboard-navigable table in server order. Case is a header (vendor, stamp,
meaning, tier, residual risk, confidence in words, mode chip, ids) plus five tabs: Decision (serif brief,
claim-versus-record cards, editable next action, contract approval), Evidence (controls in business
terms, what would change the decision, precedents, facts with provenance popovers), Agent activity (18b's
`<RunCanvas>` replaying `/cases/{id}/trace`, plus the workload sentence), Audit trail (timeline, Replay
decision with the P19 human-override sentence, dossier downloads, Open review) and Technical details (the
only place codes lead). No decision logic, no API changes, no hand-written payloads.

## 4. Components

```
/console/cases → CasesPage
  useCases()  GET /cases  (server order: residual risk desc)
  usePendingCount(items)  GET /cases/{id} for the first 40, counts contracts in pending_approval
  <Summary>  "7 cases. 3 need the TPRM lead; 1 is waiting for the vendor; 2 approvals are waiting for sign-off."
             (tooltip: "Counted from the 40 most at-risk cases.")
  <FilterChips name="outcome"|"tier" counts>   ← useSearchParams (?outcome=ESCALATE&tier=T1, repeatable)
  <CaseTable rows onOpen>  roving tabindex; ArrowUp/Down move, Enter/click → navigate(`/cases/${id}`)
     Case (vendor + <Identifier case_id>) · <OutcomeBadge> · Tier · Risk (number + 48px bar) · Status · Created (relative, <Tooltip> absolute UTC)
  <EmptyState> "No cases yet. Start an assessment to see the agents work." [Start an assessment → /]

/console/cases/:caseId → CasePage
  useCase(id), useCaseTrace(id)  GET /cases/{id}/trace
  <CaseHeader> vendor 28px · <OutcomeStamp> · meaning · Tier · Residual risk · confidence sentence
               (unverified controls by title, no codes) · <ModeChip modeChipText({kind:"mode", mode: trace[0].mode})> · <Identifier case_id> <Identifier run_id>
  <AnimatedTabs> Decision | Evidence | Agent activity | Audit trail | Technical details   (?tab= in the URL)
   DecisionTab
     <TracingBeam> <BriefColumn> headline (Serif 21px) ; why-points:
         claim+record → <ClaimRecordPair> claim card (claim tint) ≠ record card (record tint; clash text when values differ;
                         Zetaris request id from the matching fact's provenance when present)
         otherwise    → serif sentence
     <NextActionPanel sticky> To (role words), Subject, <Textarea serif> body, Copy (clipboard → fallback select()),
                              Download .txt (blob "Subject: …\n\n<body>\n", draft-N.txt)
     <ContractBlock> per contract: state sentence; pending_approval → role <Select> (from risk.approvals_required +
                     policy roles present in the case), name, rationale with live "n / 30", Approve contract / Reject contract
                     → POST /contracts/{id}/approve {by, role, decision, rationale}; toast "Contract approved" + outbox file name;
                     executed → "Sent to the outbox: <file>" (from the approval response or the audit trail when known)
   EvidenceTab  controls (title, met / not met / unverified, what would satisfy it from counterfactuals); "What would change this
                decision" (de-duplicated by control, question texts from GET /questions); precedents considered (id, lead, conditions,
                applied or not and why, from failed_criteria); <FactsTable> control title · fact in words · value · system label ·
                <ProvenanceChip> popover (record key, query id, Zetaris request id or quote)
   AgentActivityTab  <RunCanvas source={{kind:"events", events: trace, mode}} /> paced, speed control (18b's);
                     workload sentence or "The workload was not recorded for this case."
   AuditTrailTab  <Timeline> created; each contract issued / approved / rejected (who, role, rationale from risk.approvals);
                  each review (reviews[]); each replay run this session (component state)
                  Replay decision → POST /cases/{id}/replay → <ReplayResultView>: "Decision replays identically" |
                     "The replay differs in: the outcome, …" (diff field → words; failing checks named) |
                     human_override → "Machine decision replays identically; the TPRM lead overrode it to Approve with
                     conditions on <date>: <rationale>"
                  Download dossier (HTML) / (Markdown) → GET /cases/{id}/dossier?format=…; Open review → /review/:caseId
   TechnicalTab  reason codes + meanings; control table with evidence chips (<Identifier>); contradictions, counterfactuals
                 raw; signed contracts (id, signature prefix, issued, expires); <JsonViewer> raw CaseDetail (collapsed)
```
