# Arbiter sample data (synthetic)

All enterprise records under `sample/` are **synthetic** fiction for hackathon evaluation. They do not represent real vendors.

## Sources

| Path | Origin |
|---|---|
| `sample/systems/*.json` | Generated by `data/generator/generate.py` from `scenarios.yaml` |
| `kev/kev_snapshot.json` | Filtered subset of the [CISA KEV catalogue](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) (CC0); see `kev/SOURCE.md` |
| `evals/labels.jsonl`, `splits.json`, `truth_facts.jsonl` | Generator output (labels are author expectations, not model output) |
| `evals/inline/*.json` | Inline submission fixtures |

## Regenerate

```bash
python run.py generate-data --refresh-kev --seed 2026 --as-of 2026-10-26  # once, network
python run.py generate-data --seed 2026 --as-of 2026-10-26                 # offline, idempotent
```

Committed outputs are kept small (under 2 MB total).
